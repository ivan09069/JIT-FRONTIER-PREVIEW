# JIT FRONTIER - Public Preview
Find the gap. Build the proof.

Public evaluation snapshot of the JIT discovery engine, v0.1.2, published by ivan09069. The active research branch and private evidence remain separate.

## Run locally
Python 3.10+; no third-party dependencies.

    python -m unittest discover -s tests -v
    python jit_frontier.py --fixture demo_sources.json --out demo-report

Open demo-report/index.html. The included fixture is fictional and explicitly labeled demonstration data. Optional live public metadata retrieval is experimental; avoid supplying credentials in this preview. Use a fresh output directory for each run.

## Evidence boundary
Source metadata and pairings are unverified hypotheses, not novelty, feasibility, safety, market demand, or patent claims. Please submit reproducible feedback using GitHub Issues.
